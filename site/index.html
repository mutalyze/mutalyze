DETERMINISTIC · PER-TURN · NEVER LEAVES YOUR MACHINE

Your agent is mutating your code.

Coding agents run for hours with little supervision. Every edit and command is a mutation to your codebase. mutalyze reads the session transcript and flags every mutation that breaks your CLAUDE.md rules — which rule, which turn, with the exact command or edit that proves it. No language model decides.

Then it makes those rules stick: it finds the rules you only ever said in chat, keeps them in one store across projects, and puts the relevant ones back in front of the agent when a long session gets compacted.

Three files. One comparison.

Your rules live in one file. Your agent's behavior lives in another — the JSONL transcript Claude Code writes to disk. mutalyze reads both and lines them up.

    Agent mutates

    Every tool call — each edit, each command — is a change to your repo, recorded turn by turn.

  2. 02

    mutalyze reads

    It compiles your CLAUDE.md into checkable rules and walks the transcript deterministically. No LLM in the loop.

  3. 03

    Mutations flagged

    Each broken rule is reported with its id, the turn, and the command or edit that proves it. Open the transcript and see it yourself.

Rules the next session still knows.

A rules file is read once, at the start, in one repo. Half your real rules were never written down at all — you typed them at the agent mid-session and they died with the conversation. mutalyze closes that loop, and every step is yours to approve.

  1. FIND

    Rules you never wrote down

    rules mine reads your past sessions for instructions you gave in chat, cites the session and line, and ranks them by how often you repeated yourself. It reads only your messages — never the agent's.

  2. KEEP

    One store, stackable

    Approved rules live in a store that outlives the repo, grouped into bundles you stack — a base set plus a per-project overlay. Duplicates and contradictions are flagged, never silently resolved.

  3. HOLD

    Survives compaction

    When a long session gets squeezed and the rules fall out of context, context puts back the ones that matter — ranked against what the agent just touched and what you asked for.
